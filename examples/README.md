# Examples

**Fully synthetic** samples so you can see what the system produces before running it. The person, jobs, and
numbers below are invented — not real career data. They show the *target shape* of the two main artifacts:

- `sample-profile-core.md` — what a filled compressed profile digest looks like (the file read by default
  during scans and drafting).
- `sample-digest.md` — what a weekly digest looks like.

Your real versions are generated by `jobscan-onboarding` and live outside the repo (git-ignored).
