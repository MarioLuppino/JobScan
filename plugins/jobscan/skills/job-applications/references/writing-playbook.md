# Writing playbook — résumé & cover-letter mechanics

The competency→evidence map decides *what* to say; this file governs *how* to say it.

## Quantify first

Every accomplishment leads with a number where one exists: amounts, counts, people, percentages, timespans,
scale. "Managed six multi-year projects supported by $115k+ in competitive funding" beats "managed research
projects." If a bullet has no number, ask whether a real metric exists before settling for a qualitative
claim.

## Compress ruthlessly

Cut impressive-but-irrelevant material for the specific role. A tailored résumé is defined as much by what it
omits as what it includes. Prefer one strong item over three weak ones. Trim adjectives that aren't backed by
evidence — "strong communicator" is only allowed if a concrete result sits behind it.

## STAR extraction (for cover letters & interview prep)

Behind each mapped competency is usually a story: Situation, Task, Action, Result. Pull the Result (quantified)
forward. These double as interview answers — offer to convert the key mapped bullets into STAR stories once
the documents are solid.

## Natural keyword integration

Mirror the posting's exact terms **where they are true** — job title language, named tools, certifications,
regulatory/legal terms. Integrate them into real accomplishment sentences, in context. Never keyword-stuff,
never use white text, never list a skill the user doesn't have. Pull the keyword set from the structured job
summary rather than re-reading the full posting.

## Strengths-only framing (in the documents)

Résumés and cover letters state what the candidate *brings*, not what they lack. Do the honest gap analysis in
the fit assessment (step 2) — that's where "this gap may be fatal" belongs — but the delivered documents lead
with strengths. In a cover letter, a gap is acknowledged only when doing so lets you redirect to an adjacent
strength; never volunteer a weakness the posting didn't raise, and never name a missing tool as a disclaimer.

## Academic → industry translation

Translate specialist framing into the target sector's language (dissertation → multi-year budgeted research
program; grant PI → project budget ownership; lab management → operations/logistics; teaching → training).
Keep academic framing only when the role is research-heavy. The user's profile carries a translation table —
extend it whenever you find a phrasing that lands.

## Cover-letter arc

Open with specific mission alignment to the employer; structure the body around the employer's priority order
(from posting deconstruction), each paragraph anchored to mapped evidence and a number; close with a warm,
concrete invitation to discuss. Match the register to the sector (formal for government, warmer for
mission/non-profit, crisp for corporate/sales) and to the user's own voice file.
