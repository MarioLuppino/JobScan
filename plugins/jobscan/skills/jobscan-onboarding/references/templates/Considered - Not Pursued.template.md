# Considered — Not Pursued (do-not-resurface list)

Roles that surfaced in a scan and were **seen and passed on** (not applied to, no packet built). The scan
screens candidates against this file *in addition to* `Applied Index.md`, so a role you already declined
doesn't keep reappearing week after week. Add a row whenever you tell the scanner to drop a listing, or when
a digest role is reviewed and skipped.

This is the file-based equivalent of a "do-not-resurface" memory — it lives in the archive so it survives and
scales. Distinct from `Applied Index.md`, which tracks packets actually built.

**Columns:** `Employer` · `Role` · `Reason` (why passed) · `Date` · `Permanent?` (Y = never resurface;
N = okay to reconsider if it reappears substantially changed).
